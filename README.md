# 🎬 UsePopcorn – React Movie App

A dynamic web application built with **React** that allows users to search for movies via an external API, add them to a personal watchlist, and rate watched titles.  
This project demonstrates practical use of **React hooks**, **state management**, **conditional rendering**, and **local storage** for persistent data.

---

## 🚀 Features

-  **Movie Search:** Fetch movies from an external API in real-time.  
-  **Watchlist Management:** Add and remove movies from your personal watchlist.  
-  **Movie Rating:** Rate and track watched movies with custom ratings.  
-  **Data Persistence:** Save user data locally using `localStorage`.  
-  **Custom Hooks:** Manage movie fetching and local storage through reusable hooks.  

---

## 🧠 Technologies Used

- **React.js**  
- **JavaScript (ES6+)**  
- **CSS3**  
- **Local Storage API**  
- **OMDb API** *(for fetching movie data)*  

---

## 🧩 Key React Concepts

- **useState**, **useEffect**, and **custom hooks** for logic separation  
- **Conditional rendering** for UI updates  
- **Component-based architecture** for scalability
